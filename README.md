# Knowledge-graph-building-using-text

At First Create a virtual environment and install all the packages mentioned in the requirement.txt file 

create virtual environment by using the commad 
python -m venv C:\path\to\new\virtual\environment

For Creating virtual environment in the current directory
python -m venv venv

install packages by using the command 
pip install -r requirement.txt

Excute the app.y file
